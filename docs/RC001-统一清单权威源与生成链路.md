# RC001 统一清单权威源与生成链路

## 1. 唯一权威清单位置
- 权威清单文件：`contracts/unified-catalog.json`
- 清单 Owner：`backend-core`
- 只读消费者：`shell-frontend`、`module-factory`、`security-release`

## 2. 生成链路
1. 开发者先更新 `contracts/unified-catalog.json`。
2. 提交实现改动前，运行 `tools/manifest-first-gate.js` 做一致性检查。
3. PR 阶段由 `.github/workflows/manifest-first-gate.yml` 自动校验。
4. 通过后才允许进入后续构建/发布流程。

## 3. 生效规则
- 清单合并到 `main` 后立即生效。
- 若实现改动未同步清单，PR 直接阻断。

## 4. 下游读取
- 主壳运行时读取清单并执行校验分级。
- 模块工厂按清单约束导出 validator 规则。
- 发布安全按清单校验发布前置条件。
