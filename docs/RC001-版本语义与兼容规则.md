# RC001 版本语义与兼容规则

## 1. 版本格式
- 采用 `major.minor.patch`。
- 示例：`1.2.3`

## 2. 变更判定
- **major**：破坏性变更（删除字段、改字段语义、默认行为不兼容）。
- **minor**：向后兼容增强（新增可选字段、新增非强制能力）。
- **patch**：兼容性修复（修正描述、修复内部错误，不改契约语义）。

## 3. 兼容规则
- 旧客户端必须能忽略新增可选字段。
- minor/patch 不得把可选字段升级为必填。
- major 变更必须附迁移说明与回滚说明。

## 4. 发布门禁
- PR 需声明本次变更版本级别。
- 若声明级别与实际变更不一致，CI 阻断。
