# RC001 错误码分段与弃用策略

## 1. 错误码分段
- `10xxx`：认证与会话
- `11xxx`：清单与契约校验
- `12xxx`：签名与完整性
- `13xxx`：分发与下载
- `14xxx`：审计与可观测
- `19xxx`：系统兜底错误

## 2. 统一错误结构
- `code`
- `message`
- `details`
- `traceId`
- `retryable`

## 3. 弃用流程
1. `announce`：公告弃用，给出替代项。
2. `deprecated`：保留可用但输出弃用标记。
3. `removed`：移除并阻断旧码使用。

## 4. 最小示例
- 旧码：`11021`（deprecated）
- 新码：`11031`
- 替代说明：清单字段校验从旧规则切换到新规则。
