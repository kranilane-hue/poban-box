# RC001 主壳运行时校验分级与降级路径

## 1. 分级定义
- `fatal`：必须阻断当前模块加载。
- `warn`：允许继续，但提示能力受限。
- `info`：仅记录日志，不阻断流程。

## 2. 判定矩阵（最小版）
- 清单签名无效 -> `fatal`
- 清单字段非关键缺失 -> `warn`
- 非关键元数据不完整 -> `info`

## 3. 降级路径
1. `fatal`：尝试回退到最近可用版本。
2. 回退失败：进入安全壳态，只保留基础能力。
3. UI 提示：展示原因 + 可执行动作（重试、重载、上报日志）。

## 4. 记录字段
- `moduleId`
- `catalogVersion`
- `level`
- `errorCode`
- `timestamp`
