# RC001 DecisionId 例外审批机制

## 1. 适用场景
- 紧急安全修复
- 生产故障止血
- 合规时限要求

## 2. 必备字段
- `DecisionId`（格式：`DEC-YYYYMMDD-XXX`）
- 申请人
- 审批人（至少两人）
- 生效范围
- 到期时间
- 补偿动作与截止时间

## 3. 审批流程
1. 提交例外申请并附 `DecisionId`。
2. 双审批通过后打上例外标记。
3. CI 验证例外字段完整性。
4. 到期自动失效，失效后恢复硬阻断。

## 4. 审计要求
- 每次例外必须留痕：PR、审批记录、时间戳、最终补偿结果。
- 无 `DecisionId` 的例外请求一律拒绝。
